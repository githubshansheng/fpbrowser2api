Nana Banana 2 / Nana Banana Pro · 图片 API 接入文档

本文档分别说明异步接口 /v1/videos、同步生成接口 /v1/images/generations 和 OpenAI 兼容编辑接口 /v1/images/edits。

异步接口：/v1/videos

异步接口提交后立即返回任务 ID，需要继续轮询 /v1/videos/{task_id} 获取结果。图片模型通过该接口创建时，seconds 可省略；如果传入则必须写成字符串 "4"，省略时按 "4" 处理。duration 如果传入也必须为 4。

异步模型

模型说明
nana-banana-2Nana Banana 2，默认 1K/2K 图片任务
nana-banana-proNana Banana Pro，默认 1K/2K 图片任务
nana-banana-2-4kNana Banana 2，固定 4K 图片任务
nana-banana-pro-4kNana Banana Pro，固定 4K 图片任务

异步提交示例

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nana-banana-2",
    "prompt": "a cute banana mascot wearing sunglasses, studio lighting",
    "seconds": "4",
    "aspect_ratio": "1:1",
    "resolution": "1k",
    "images": ["https://your-cdn.com/ref.jpg"]
  }'

异步请求字段

字段说明
modelnana-banana-2 / nana-banana-pro / nana-banana-2-4k / nana-banana-pro-4k
prompt生成提示词
seconds可选；如果传入，必须使用字符串 "4"；省略时默认按 "4" 处理
duration可选；如果传入必须为 4
images参考图 URL 数组，最多 7 张
aspect_ratio支持 16:9 / 9:16 / 3:4 / 4:3 / 1:1
resolutionnana-banana-2 / nana-banana-pro 支持 1k / 2k；4K 模型固定为 4k

异步查询任务

curl https://xxx.xxx.xxx/v1/videos/8c7e4b0e6f3b4b0a9e0a0d8f4f0c1234 \
  -H "Authorization: Bearer api-key"

同步接口：/v1/images/generations

同步接口会在服务端等待图片任务完成后再返回，响应格式对齐 OpenAI 图片生成接口：顶层包含 created 和 data。同步接口使用独立模型名，不与异步模型混用。

同步模型

模型对应异步模型
nana-banana-2_syncnana-banana-2
nana-banana-pro_syncnana-banana-pro
nana-banana-2-4k_syncnana-banana-2-4k
nana-banana-pro-4k_syncnana-banana-pro-4k

同步请求示例

curl -X POST https://xxx.xxx.xxx/v1/images/generations \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nana-banana-2_sync",
    "prompt": "a cute banana mascot wearing sunglasses, studio lighting",
    "size": "1024x1024",
    "n": 1,
    "images": ["https://your-cdn.com/ref.jpg"]
  }'

同步请求字段

字段说明
model必须使用 *_sync 同步模型名
prompt生成提示词
sizeOpenAI 风格尺寸，例如 1024x1024 / 2048x2048 / 4096x4096；也可使用 1k / 2k / 4k
n当前仅支持 1
images / image参考图，可用于图生图 / 编辑
response_format支持 url；如果后端结果提供 b64_json，也可返回 b64_json

同步返回示例

{
  "created": 1714200180,
  "data": [
    {
      "url": "https://xxx.xxx.xxx/generated/image.jpg"
    }
  ]
}

OpenAI 兼容编辑接口：/v1/images/edits

该接口接受 JSON URL/data URL，也接受 1–7 个重复的 multipart image 文件字段。模型仍使用上表中的 *_sync 名称，n 只能为 1。Nana Banana 不支持蒙版语义，传入 mask 会返回 400；原有 /v1/images/generations + JSON images 改图方式保持可用。

curl -X POST https://xxx.xxx.xxx/v1/images/edits \
  -H "Authorization: Bearer api-key" \
  -F "model=nana-banana-2_sync" \
  -F "prompt=保留主体，把背景改为夜晚霓虹城市" \
  -F "image=@source.png" \
  -F "n=1"
