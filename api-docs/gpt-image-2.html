GPT Image 2 · 图片 API 接入文档

本文档分别说明异步接口 /v1/videos、同步生成接口 /v1/images/generations 和 OpenAI 兼容编辑接口 /v1/images/edits。

异步接口：/v1/videos

异步接口提交后立即返回任务 ID，需要继续轮询 /v1/videos/{task_id} 获取结果。图片模型通过该接口创建时，seconds 可省略；如果传入则必须写成字符串 "4"，省略时按 "4" 处理。duration 如果传入也必须为 4。

异步模型

模型说明
gpt-image2-1kGPT Image 2，1K 图片任务
gpt-image2-2kGPT Image 2，2K 图片任务
gpt-image2-4kGPT Image 2，4K 图片任务

异步提交示例

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image2-2k",
    "prompt": "retro neon poster, cyberpunk girl",
    "seconds": "4",
    "aspect_ratio": "9:16"
  }'

异步多图参考示例

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image2-2k",
    "prompt": "the character from the reference photo, in a futuristic city",
    "seconds": "4",
    "images": ["https://your-cdn.com/ref.jpg"]
  }'

异步请求字段

字段说明
modelgpt-image2-1k / gpt-image2-2k / gpt-image2-4k
prompt生成提示词
seconds可选；如果传入，必须使用字符串 "4"；省略时默认按 "4" 处理
duration可选；如果传入必须为 4
images参考图 URL 数组，可用于图生图 / 编辑
aspect_ratio / ratio支持 16:9 / 9:16 / 3:4 / 4:3 / 1:1

异步查询任务

curl https://xxx.xxx.xxx/v1/videos/8c7e4b0e6f3b4b0a9e0a0d8f4f0c1234 \
  -H "Authorization: Bearer api-key"

同步接口：/v1/images/generations

同步接口会在服务端等待图片任务完成后再返回，响应格式对齐 OpenAI 图片生成接口：顶层包含 created 和 data。同步接口使用独立模型名，不与异步模型混用。

同步模型

模型对应异步模型
gpt-image2-1k_syncgpt-image2-1k
gpt-image2-2k_syncgpt-image2-2k
gpt-image2-4k_syncgpt-image2-4k

同步请求示例

curl -X POST https://xxx.xxx.xxx/v1/images/generations \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image2-2k_sync",
    "prompt": "retro neon poster, cyberpunk girl",
    "size": "2048x2048",
    "n": 1
  }'

同步请求字段

字段说明
model必须使用 *_sync 同步模型名
prompt生成提示词
sizeOpenAI 风格尺寸，例如 1024x1024 / 2048x2048 / 4096x4096；也可使用 1k / 2k / 4k
n当前仅支持 1
images / image参考图，可用于图生图 / 编辑
response_format支持 url；如果后端结果提供 b64_json，也可返回 b64_json

同步返回示例

{
  "created": 1714200180,
  "data": [
    {
      "url": "https://xxx.xxx.xxx/generated/image.jpg"
    }
  ]
}

OpenAI 兼容编辑接口：/v1/images/edits

该接口支持 JSON URL/data URL 和 multipart 文件上传。可重复提交 1–7 个 image 字段，并可额外提交一个 mask。模型使用 *_sync 名称，n 只能为 1。

curl -X POST https://xxx.xxx.xxx/v1/images/edits \
  -H "Authorization: Bearer api-key" \
  -F "model=gpt-image2-1k_sync" \
  -F "prompt=只修改蒙版区域" \
  -F "image=@source.png" \
  -F "mask=@mask.png" \
  -F "n=1"
